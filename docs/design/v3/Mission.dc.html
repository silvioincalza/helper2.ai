Mission

Our mission

Help people find the right AI resource for their need, and show the proof behind every answer.

Why Helper2.ai exists

New AI models, tools, agents, MCP servers and papers appear every day. General search engines mix them with marketing pages and old content, so it is hard to know what is real and current.

Helper2.ai searches only sources about AI, tells you which sources it searched, and shows where every result comes from and when it was checked.

What we promise

  • Proof before opinion. The guide only recommends a resource when it can quote a real source that supports the choice.
  • Honest coverage. We list every source we search and show what each one returned. We do not claim to search the whole web.
  • No invented facts. We never fill in dates, popularity or other facts that no source stated.
  • Open by default. The source code is public under the Apache-2.0 license.
  • Privacy first. No ads, no tracking, and we never sell data.

How we mark AI text

  • On the screen, every text written by an AI model has a label, such as “AI”, “AI reasoning”, “AI summary” or “Extracted by AI”.
  • In the page, the same text carries the HTML attribute data-ai-generated="true", and data-ai-model with the model name when we know it.
  • In our API, a guide answer has an aiContent object that names the provider, the models and the fields they wrote. Catalog values carry an origin such as AI_SUMMARY or AI_EXTRACTED.
  • Quotes, titles and links are never written by AI. They come from the sources.

Who is behind it

Helper2.ai is an independent project by Silvio Incalza, a software engineer based in Switzerland. The AI guide runs on NVIDIA Nemotron models served by Nebius Token Factory.
