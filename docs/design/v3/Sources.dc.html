How we search

  1. 01 · Ask

    One query, every source

    Your search goes to all enabled sources at the same time.

  2. 02 · Merge

    Duplicates become one

    The same resource from several sources is shown once, with every source named.

  3. 03 · Prove

    Picks quote their source

    The guide only recommends what it found, and quotes the sentence that supports it.

  4. 04 · Fair

    No paid ranking

    No source pays to rank higher. There are no ads in the results.
