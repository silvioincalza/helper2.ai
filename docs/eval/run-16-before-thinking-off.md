## How to read this

- "Checks confirmed" is confirmed / total constraint checks over the AI picks. Not confirmed means the resource's own text does not show it, not that it is false.
- Previous runs are in [docs/eval/](./). Run 15 (eval/run-15-prod-previous-image.md (in git history)) used the image deployed before `47b064a`; this run measures `47b064a`, whose backend matches `main`.
- "(cache)" marks an answer served from the 24-hour cache; its latency is left out of the percentiles.
- "Kept" counts only AI-reasoned picks that passed the evidence check. Plain search results shown as a fallback count 0.
- "Top pick" is the first AI-reasoned pick; "no AI pick" means the model chose nothing or everything was rejected.
- `x01` is a nonsense query. The honest result is NO_CANDIDATES or no AI picks.
- `b14` is in Italian, to check that the planning model turns any language into English search terms.
- Relevance of the top pick, judged by hand on 26 Oct 2026 (does it do what the request asks?): **14 of 19 real queries relevant**. Not relevant: b03 (an embedding experiment, not a small laptop model), b04 (a Streamlit app, not a library) and u04 (an NLP pipeline repo, not something that writes the reply). No AI pick: b11 and u01. b07 and b09 were judged from the title and quote only. x01 (nonsense) correctly got no AI pick.
- The USE_AI queries (u01–u04) get developer projects, not ready-made apps. Relevant to the topic, but an everyday user would still have to install something.
- Top picks are not stable between runs: run 15 and run 16 chose a different top pick (or none) for 10 of 19 real queries.
- Latency is higher than in run 15 (p50 21.0 s vs 18.0 s, p90 46.4 s vs 30.0 s). Per-call timings are in the backend log (`guide timings:`); they were not collected for this run.
